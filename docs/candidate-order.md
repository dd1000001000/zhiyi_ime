# 候选的位置

第一页的候选分两层排出来（`engine/src/engine.cc` 的 `translate_composition`）：

## 一、排序

决定普通候选的先后，依次是：

1. 翻译器（`pinyin_translator.cc` / `wubi_translator.cc`）：词典打分、用户词、导入的词表、学习过的偏好；
   **手动调序**（设置里拖过顺序的词，候选带 `pinned` 标记）排在最前；
   全拼的**长词提前**（雾凇式，如 `xian` 的“西安”）放在第 4 位，手动调序的词多于 3 个时放在它们之后。
   快路径（Top-N 索引）和慢路径顺序一致：先手动调序，再长词。
2. 推荐模型（`laya_rerank.cc`）：把它挑的词挪到第一位、标上推荐；长拼音时可能换成它自己组的整句。
   **手动调序的词不动**：模型只在它们之后挑，挑中的放在它们后面。

## 二、置位

固定位置的候选在排序之后放进去（`engine/src/candidate_placement.h`），模型看不到也挪不动它们；
翻页时重新查询第一页也经过同样的步骤，所以每次结果一样。

| 来源 | 位置 | 优先级 |
|---|---|---|
| 快捷短语（[快捷短语](custom-phrases.md)） | 文件里写的位置（1–9） | 最高 |
| 内置日期时间（拼音读作日期 / 时间 / 星期） | 第 2 位起 | 次之 |
| 中文输入里的英文单词（`english.position_in_pinyin`，默认第 2 位；输入不是完整拼音时第 1 位） | 第 2 位 | 再次 |

规则：

1. 普通候选里和置位候选文字相同的去掉（只出现一次）；两个置位候选文字相同时留优先级高的。
2. 按优先级依次放：放到它的位置，被占了就往后找第一个空位；位置超过末尾就放在最后。
3. emoji 在置位之前插到它的词后面，不会挤占置位候选的位置（以前第一个词有 emoji 时，英文单词会被挤到第 3、4 位）。
4. 最后截到一页；被挤出去的普通候选出现在下一页。
