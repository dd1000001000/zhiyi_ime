# 快捷短语

输入一串编码，在候选的指定位置出现事先写好的短语（#40）：打 `dh` 出手机号，打 `wjx` 出 ★ ☆，打 `dz` 出多行地址。
另外内置了日期、时间和星期：拼音读作“日期”“时间”“星期”就出（`riqi`、`rq`、`shijian`、`shij`、`sj`、`xq` 都算），`/` 菜单里也有。

## 在哪里设置

“设置 > 快捷短语”，一张卡片，按钮仿照微软拼音的“用户自定义短语”（添加、导入、导出、清除）：

- **启用快捷短语**：总开关（`phrases.enable`，默认开）。
- **日期 / 时间 / 星期**：内置的三组（`phrases.builtin_date` / `builtin_time` / `builtin_week`，默认开）。只管打字时出不出，`/` 菜单里的不受影响。
- **添加**：弹出“添加短语”，一次填一条：编码（最多 32 个小写字母，不以 u、v 开头，因为 u、v 开头是
  [U 模式和 V 模式](uv-mode.md)）、在候选窗口中的位置（1–9）、短语（一行）。编码不对或短语为空时“添加”是灰的。
- **导入**：导入搜狗的 `phrases.ini` 或 Rime 的 `custom_phrase.txt`；已有的（编码和内容都相同）跳过。
- **导出**：存成搜狗的 `phrases.ini`（UTF-16，搜狗可以直接导入）或 Rime 的 `custom_phrase.txt`
  （多行和带日期变量的短语 Rime 不支持，不导出，会提示跳过了几条）。
- **清除**：确认后删除全部短语。
- 下面列出已有的短语，每条可以“编辑”（同样的对话框；多行的短语编辑时是多行框）“删除”。

开关在点“应用”或“确定”后生效；短语的增删改立即写入文件、立即生效。
多行短语可以直接编辑下面的短语文件来写，保存后立即生效，不用重启输入法。
导入的、文件里手写的以 u、v 开头的短语保留；全拼里 U/V 模式打开时它们打不出来，五笔、双拼里照常。

## 文件

短语保存在数据文件夹的 `phrases\phrases.ini`（默认 `%USERPROFILE%\zhiyi\phrases\phrases.ini`），格式同搜狗输入法：

```
; 分号开头是注释
dh,1=13901234567
wjx,1=★
wjx,2=☆
dz,1=
北京市西城区
1号院
rq,1=#$year年$month月$day日 星期$weekday_cn
```

- 每条是 `编码,位置=短语`。编码只能是字母（不分大小写，最多 32 个）；位置是 1–9，超过 9 按 9。同一个编码可以有多条。
- 等号后直接换行，下面各行都是这条短语的内容，直到下一条 `编码,位置=`；末尾的空行不算。
- 以 `#` 开头的短语填入当时的日期时间，变量同搜狗：

| 变量 | 含义 | 例 |
|---|---|---|
| `$year` / `$year_yy` | 年（4 位 / 2 位） | 2026 / 26 |
| `$month` / `$month_mm` | 月（不补零 / 两位） | 3 / 03 |
| `$day` / `$day_dd` | 日（不补零 / 两位） | 5 / 05 |
| `$weekday` | 星期（0 是星期日） | 6 |
| `$fullhour` / `$halfhour` | 时（24 小时 / 12 小时，两位） | 15 / 03 |
| `$ampm` | AM / PM | PM |
| `$minute` / `$second` | 分 / 秒（两位） | 04 / 09 |
| 以上各变量加 `_cn` | 中文数字 | `$year_cn` 二〇二六，`$month_cn` 十，`$day_cn` 三十一，`$weekday_cn` 六，`$ampm_cn` 下午，`$minute_cn` 零四 |

- 读文件时 UTF-8（有无 BOM 都可）、搜狗导出的 UTF-16 和 GBK 都认；保存为带 BOM 的 UTF-8。
- 上限同搜狗：每条最多约 3 万字，共 10 万条。设置页最多列出前 150 条，其余直接编辑短语文件。

## 怎么出现

- 按实际敲的字母整串完全匹配（隔音符号 `'` 不算）：全拼、首字母、双拼、五笔都一样；英文状态和符号面板（`/`）里不出现。
- 短语放在它的位置上，原来的候选依次后移；位置超过一页时落到后面的页。两条抢同一个位置时，排在文件前面的先占，后面的顺延。
  候选的位置规则见 [候选排序 — 固定位置的候选](candidate-ordering.md#7-固定位置的候选)。
- 多行短语在候选里只显示第一行加“…”，上屏的是全文。
- 内置的日期、时间、星期按读音出现（只在拼音里）：每个音节打全或只打开头都算，如 `riqi`、`rq`、`riq`，
  `shijian`、`shij`、`sj`，`xingqi`、`xingq`、`xq`；只打一个音节（`shi`）不算。
  日期：2026年10月31日、2026-10-31、2026/10/31、2026.10.31、20261031、二〇二六年十月三十一日；
  时间：15:04、15:04:09、下午3:04、下午三点零四分；星期：星期六、周六、礼拜六。
  第一种放在第 2 位（第 1 位还是拼音原来的第一个候选，如“时间”），其余依次在后面。自己写了同编码的短语（比如 `sj`）就只出自己的。
- `/` 菜单最后三类是日期（`/rq`）、时间（`/sj`）、星期（`/xq`），始终都在，不受上面开关影响。
- 同一次输入里，日期时间只取一次，翻页时不会变。

## 隐私

短语里常有手机号、地址这类私人信息：

- 选中的短语**不记入学习**（不调整候选顺序，也不进学习记录）。
- **不作为推荐模型的上文**，也不进续写；学习模式下不送去翻译。
- 出现过短语的那次输入**不进入输入收集**（体验改进计划的第二档）。
- 短语文件只在本机；用户数据备份里会包含它（“快捷短语”这一项，没有短语时不写入）。

程序文本框里光标前的文字（包括已经上屏的短语）仍可能被读作推荐的上文，那是文档本身的内容，只在本机使用。

## 实现

- `engine/include/cxxime/custom_phrases.h`：格式解析（搜狗、Rime）、日期变量、内置日期时间、共享的短语表。
- `engine/src/engine.cc`（`phrase_requests`）：按输入找短语，作为置位请求交给 `candidate_placement.h`。
- `server/src/phrase_service.cc`：启动时读文件，监视文件夹，文件一变就重新读；备份的导出和合并。
- `settings/editor_phrase_panel.cc`：设置页，直接读写短语文件。
- 候选来源 `CandidateSource::kPhrase`：学习、上文、翻译、输入收集各处都据此排除。
