# 离线包

翻译模型、语音模型和学习模式的语言包都要在设置里下载，下载地址在 GitHub。国内网络连 GitHub 常常不稳，大文件容易下到一半断掉（[#52](https://github.com/dd1000001000/zhiyi_ime/issues/52)）。这时可以改用离线包：在别处下载好一个文件，再在设置里导入。

## 下载

设置里每处“下载”按钮旁边都有“离线包下载页”，打开的是魔搭社区上的 [知意输入法离线包](https://www.modelscope.cn/models/dd1000001000/zhiyi_packages/files)，国内可以直接下载；链接上点右键可以复制地址，交给浏览器或下载工具。

| 离线包 | 内容 | 在哪里导入 |
|---|---|---|
| `zhiyi-offline-translator-v<N>.zip` | 离线翻译模型和它的运行库 | “学习”页 → 离线翻译 |
| `zhiyi-offline-voice-sensevoice-v<N>.zip` | 语音模型 SenseVoice | “语音输入”页 → 语音模型 |
| `zhiyi-offline-voice-qwen3-asr-v<N>.zip` | 语音模型 Qwen3-ASR | “语音输入”页 → 语音模型（导入后自动切到这个模型） |
| `zhiyi-offline-glossary-<日期>.zip` | 全部语言包 | “学习”页 → 语言包（右上角） |

## 导入

点“从文件导入…”，选下载好的 `.zip`。也可以把 GitHub Release 里的文件一个个下载到同一个文件夹，选其中的清单（`translator.json`、`voice.json`、`voice-qwen3-asr.json` 或 `glossary.json`，旁边要有同名的 `.sig` 和清单列出的文件）。

导入和在线下载用的是同一套检查和安装流程：

1. 清单的签名用输入法内置的公钥核对，只接受知意发布的包；
2. 清单要求的最低版本（`min_app`）比当前输入法新时不导入，提示先更新输入法；
3. 每个文件取出时核对大小和 SHA-256，对不上就停下，提示重新下载；
4. 装到和下载相同的位置，装好后和下载完成一样自动打开并试用一次。

和已安装的版本相同时不导入（提示已经是这个版本）；比已安装的旧时会先问一声。语言包一次导入包里所有比本机新的语言包（没装过的也装上），导入后可以在“候选翻译”里选。

## 包的格式

一个不压缩（stored）的 zip：发布时的签名清单和它的 `.sig`，加上清单列出的全部文件，文件名不带目录。清单和在线下载时读的完全相同，所以离线包不需要单独签名。发布新版本时由打包脚本从发布文件生成，上传到魔搭。
