# 隐私与用户体验改进计划

## 用户体验改进计划

- 默认关闭。安装时有一页询问是否加入；之后可以在“设置 > 隐私”中随时开关。
- 配置项：`privacy.experience_program`（`%USERPROFILE%\zhiyi\default.json`）。
- 日志只写在本机：`%USERPROFILE%\zhiyi\logs\experience.jsonl`，超过 1 MB 时改名为
  `experience.1.jsonl`（只保留这一份旧文件）。“设置 > 隐私”可以打开日志文件夹或删除日志。
- 日志不会自动上传。只有用户自己发送（例如运行 `collect_diagnostics.ps1 -IncludeLogs`
  打包后发给开发者）时才会被别人看到。
- 由后台服务 `zhiyi-server.exe` 写入（`engine/src/experience_log.cc`），输入法模块不写这份日志。

### 记录的内容

每行一个 JSON 对象，`event` 是记录类型，`t` 是 UTC 时间。

| 记录 | 何时写入 | 内容 |
|---|---|---|
| `start` | 后台服务启动且计划开启时 | 输入法版本、Windows 版本号、CPU 核数、内存大小（GB） |
| `config` | 首次开启以及设置改变时 | 影响输入法行为的设置：中文输入方式、拼音方案、首字母模式、模糊音开关和组合、自学习、每页候选数、字号、主题、界面语言、推荐模型开关、英文纠错、英文单词模式、渲染方式、布局、4 个切换键 |
| `stats` | 每 30 分钟、关闭计划时、后台服务退出时 | 这段时间的分钟数；处理的按键数；出错次数；按键处理耗时分布（<5、<10、<20、<50、<100、<200、≥200 毫秒各多少次）和最大耗时；选择第 1–10 个候选的次数；有推荐词时的选择次数及其中选了推荐词的次数；推荐模型是否加载成功/失败、调用次数、调整顺序的次数、最近一次推理耗时 |

### 不记录的内容

- 任何输入内容：按了哪些键、拼音、候选词、上屏的文字、英文单词。
- 正在使用的程序、窗口标题、文件名。
- 用户名、电脑名、IP 地址等身份信息。

统计只有次数和耗时，不记录单次按键的时间点。

## 开发诊断日志（与本计划无关）

`diagnostics.trace_mode`（默认 `off`）是给开发调试用的详细跟踪，开启后会记录输入的拼音编码等
内容，写在同一个 `logs` 文件夹的 `*-trace.jsonl` 中。设置界面没有它的开关，用户体验改进计划也不会
开启它。
