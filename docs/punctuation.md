# 自定义标点

中文标点下每个符号键打出什么，可以自己改（#43）：比如把 `` ` `` 改回英文的 `` ` ``（写 Markdown），把 `[` `]` 改成「」，
把 `"` 改成成对的「」。半角和全角各一栏，做法和搜狗输入法的“自定义标点”一样。

## 在哪里设置

“设置 > 高级 > 自定义标点”，点“自定义标点…”打开一张表，每个键一行：按键、中文半角、中文全角、输入中途。

- **左键单击**“中文半角”“中文全角”的格子，直接在格子里改：填要打出的字符（最多 8 个字符）；两个字符中间加空格
  表示成对（`「 」`：按一次出左边、再按一次出右边，交替）；填按键本身就是英文，和英文标点下一样；清空就是默认。
  回车或点别处保存，Esc 不改。
- **左键单击**“输入中途”，在**先上屏候选**和**接在编码后**之间切换（见下文）。
- **右键单击**格子恢复这一格的默认（安装时的标点表 `data/punctuation.json`）；在“按键”上右键恢复整行。
- 改过的格子显示为蓝色；“全部恢复默认”一次全改回去。卡片上显示改了几个键。
- 表里点“确定”后，再在设置里点“应用”或“确定”生效。

可以改的是除 `/` 以外的 31 个符号键：`/` 打开符号面板（见 [组合输入](ascii-composer.md)）。字母、数字不在其中。

## 规则：看这个键打出什么

一个键的所有规则都看它现在打出的字符（下面叫“值”），不看是哪个键：

- **只在中文标点下生效**。半角用半角栏，全角用全角栏。英文标点（Ctrl+.）下符号键就是英文，不查这张表。
- **没在打拼音时**：值是中文（或别的非英文字符）就打出它；值是这个键本身时，按键直接交给程序，和英文标点一样
  （编辑器的自动配对照常可用）；值是别的英文字符时打出那个字符。
- **拼音打到一半时**：
  - 值是中文：先上屏当前候选，再打出它（`nihao` 再按 `.` 出“你好。”）；
  - 值是英文：看这个键的“输入中途”：**接在编码后**时，值接在拼音后面一起当英文（`c++`、`name@example`），
    回车或空格原样上屏；**先上屏候选**时，先上屏候选，再打出值（`daima` 再按 `` ` `` 出“代码`”）；
  - 编码没有候选时，照旧接在后面。
- **数字后的句号**：值是“。”的键，紧跟在数字后面打出小数点（`3.14`，#32）。
- **成对**：左右交替，每个程序各自记。
- **语音输入**：识别结果里的中文标点也换成对应键当前的值，比如“，”换成 `,` 键的值；值是英文的句读
  （， 。 ？ ！ ： ； 、）后面加一个空格，和英文标点下一样（不出现连续两个空格，句末不留空格）。

下面这些跟按键位置有关、和打出什么无关的规则不变：有候选时翻页键（`- = [ ] , .`，在“按键”页设置）先翻页；
拼音和 U 模式里 `'` 是音节分隔；双拼里 `;` 是编码；数字键选候选。

## 默认值

| 按键 | 中文半角 | 输入中途 |
| --- | --- | --- |
| `.` `,` `;` `:` `?` `!` | 。，；：？！ | 先上屏候选 |
| `\` | 、 | 先上屏候选 |
| `(` `)` `[` `]` `<` `>` | （）【】《》 | 先上屏候选 |
| `'` `"` | ‘’ “”（成对） | 先上屏候选 |
| `_` `^` `$` `~` | —— …… ￥ ～ | 接在编码后（改成英文时才用到） |
| `` ` `` | · | 先上屏候选 |
| `@` `#` `%` `&` `*` `+` `{` `}` `\|` | 英文 | 接在编码后 |
| `-` `=` | 英文 | 先上屏候选 |

中文全角一栏默认是每个键的全角字符（`.` 出 `．`，`[` 出 `［`），和以前的全角模式一样。
“输入中途”只在值是英文时有用：中文值总是先上屏候选。`` ` `` 默认“先上屏候选”（以前接在编码后），
所以英文标点下打 `daima` 再按 `` ` `` 也出“代码`”。

## 配置文件

改过的键存在配置文件的 `punctuation.keys` 里，只存和默认不同的部分：

```json
"punctuation": {
    "keys": [
        { "key": "`", "half": "`" },
        { "key": "\"", "half": ["「", "」"], "full": ["『", "』"] },
        { "key": "*", "join_code": false }
    ]
}
```

`half`、`full` 是字符串（打出它）或 `[左, 右]`（成对）；`join_code` 是“输入中途”接在编码后（`true`）还是先上屏候选（`false`）。
不合法的条目（`/`、空值、超过 8 个字符）读取时丢掉。默认值在安装目录的 `data/punctuation.json`
（`half_shape`、`full_shape`，`join_code` 是默认接在编码后的键）。
