The first release of Zhiyi IME (based on CxxIME 0.6.2).

- Recommendations: the Laya model reorders candidates by context; the recommended candidate has a blue-purple gradient star
- Fuzzy pinyin: each pair has its own switch (only en=eng and in=ing by default); fuzzy candidates come after the typed sound
- Free choice of the Chinese/English, English style, punctuation and full/half width keys, with warnings about conflicts with Windows or other programs
- English word mode with spelling correction
- Chinese and English interface and installer; the status ball follows the dark theme
- Privacy: an optional two-tier user experience improvement program, off by default, with records kept on this computer only
- New Updates page in Settings: tells you about new versions and downloads, verifies and installs them
