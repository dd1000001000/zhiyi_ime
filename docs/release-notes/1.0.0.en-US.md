- The first official release of Zhiyi IME
- Recommendations now read the text before the caret in the input box (before, only what was typed with Zhiyi IME), so pasted and existing text counts too; switching to another input box no longer carries over the previous one's text. Password fields are never read
- A new recommendation model that looks at the context and the candidates only, with longer context (up to 128 Chinese / 192 English characters): more accurate and faster
- Tier 2 of the user experience program (allow collecting your input) records the text before the caret given to the recommendation model; see the privacy notes
