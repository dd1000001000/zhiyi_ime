- 全拼后面跟声母时不再丢常用词：`womsh` 给 我们是，`zhegsh` 给 这个是 / 这个事，`tabsh` 给 他不是，`zhebsh` 给 这不是（音节路径改为按常见程度优先枚举，不再按字母顺序被截断）
- 支持儿化：音节后的 r 读作 儿，`nar` 给 哪儿 / 那儿，`zher` 给 这儿，`yihuir` 给 一会儿，`huar` 给 花儿，`wanr` 给 玩儿
- 生僻字不再占满首页：`de`、`ne`、`nv` 等单音节先出常用字和词，几乎没人用的字排到最后
- 末音节总会补全：`buzhida` 给 不知道，`xianggan` 给 香港，`huanyin` 给 欢迎
- 联想词每次最多 3 个：`bandaoti` 不再整页都是 半导体×××
