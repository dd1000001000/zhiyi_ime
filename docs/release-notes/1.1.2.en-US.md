- With a dedicated graphics card, "Run on" on the General page can move the recommendation model from the CPU to the card (DirectML: NVIDIA, AMD and Intel cards) for faster recommendations: about 9 ms each on an RTX 5070 Ti against 30-50 ms on the CPU. Choosing a card tests its speed first; it is used only when it is faster than the CPU, otherwise the CPU is restored. It takes about 500 MB of video memory. Computers without a suitable card do not show the option
- New "Recommend candidates by context" switch on the General page turns the recommendations off (Chinese and English together); the model is then not loaded
- Fixed: with fuzzy pinyin on (such as en = eng), a word learned with a wrong reading could push the whole word off the first page (typing keneng showed no 可能)
- ONNX Runtime is now the 1.24.4 DirectML build; the first start after the update rebuilds the model cache once and takes a few seconds longer
