- Fixed recommendations appearing in an empty input box in Chrome, Edge and Electron apps (Claude, VS Code): their boxes were treated as unreadable, so text typed and already sent earlier served as the context. The box's real text is read now; an empty box gets no recommendation
- In programs whose input box cannot be read, the text typed before stops being the context after 60 seconds without typing (setting `laya.context_memory_seconds`, 0 = kept)
