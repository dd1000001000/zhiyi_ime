- Offline translation has a new model: a small one distilled from Tencent Hy-MT2-7B. The download drops from about 1.2 GB to about 0.4 GB, and it is faster on the graphics card with less video memory; it is about as accurate as Hy-MT2 1.8B before (better from Chinese into English, a little worse into the other languages). If you downloaded the old one, click Check and then Update to v2 on the Learning page
- Offline translation can run on the CPU: choose CPU under Run on, so computers without a dedicated graphics card can use it too, at about 0.3 s a page
- Fixed the offline translation process using more and more memory (up to several GB) over a long session
