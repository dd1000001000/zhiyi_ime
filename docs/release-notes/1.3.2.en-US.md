- In learning mode, Ctrl+1-9 while typing types the translation of candidate 1-9 (the first sense the candidate window shows): `xianzai` then Ctrl+1 types `now`. Translations from the language pack and from the offline translation model both work; a candidate without one types nothing and the pinyin stays. While typing these keys do not reach the application (a browser does not switch tabs)
- A translation into English and other languages written with spaces gets a space before it after a letter or digit; the languages are set by `learning.space_languages` (by default the six besides Chinese and Japanese)
