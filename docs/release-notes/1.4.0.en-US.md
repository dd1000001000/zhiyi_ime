- Shuangpin: Microsoft, Xiaohe, Ziranma and Sogou, chosen on the General page of settings. The style key (Ctrl+Space by default) cycles full pinyin, initials, Wubi and shuangpin; the taskbar menu switches directly too
- Long input composed by the model: the recommendation model is replaced by one that also composes sentences. Type 4 or more syllables in one go and pause for about 0.1 s: the first candidate becomes the model's sentence for the text before the caret (starred). In testing, long phrases typed in full pinyin came first 60.7% of the time instead of 46.6%, and about twice as often with the last syllable typed as an initial or the first ones abbreviated; shuangpin too. Keys never wait for the model. The switch in settings is now "Recommend candidates and compose long input by context"
- Wubi is recommended by context too: the model orders the first page by the text before the caret; with the same switch off, candidates go by frequency and what you picked before
- Learning: sentences are learned with the words, so a word you use often is no longer kept behind a sentence learned earlier. Sentences learned before are not read anymore and are learned again
- Settings that could not be saved now say why (timed out, refused by the background service, file not writable) after waiting up to 10 s; the reason is also kept in problems.log in the logs folder (the step that failed and Windows' error text, never what you typed), which you can attach to a report
- A silent install with /D= puts a fresh install in that folder (for example with scoop); the setup window accepts an old install folder still waiting for a restart to be removed
- The diagnostics script runs on Chinese Windows
- A few settings and backup contents from versions before 1.0.0 are no longer converted
