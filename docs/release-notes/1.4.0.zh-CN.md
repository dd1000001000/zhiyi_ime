- 新增双拼：微软、小鹤、自然码、搜狗四种方案，在设置“常规”页选择。切换键（默认 Ctrl+空格）在全拼、首字母、五笔、双拼之间轮换，任务栏右键菜单也能直接切换
- 长句由模型组句：推荐模型换成能组句的新版本。一口气打 4 个音节以上的拼音，停顿约 0.1 秒后，第一个候选换成模型按上文组出的句子（标星号）。测试中全拼长句的首选准确率从 46.6% 提高到 60.7%，最后一个字只打声母、前面简拼后面全拼的长句约提高一倍；双拼同样适用。打字时不等模型，按键速度不变。设置里的开关改名为“按上文推荐候选和组长句”
- 五笔也按上文推荐：第一页候选由模型按光标前的文字排序，关掉上面的开关就按词频和学习记录排列
- 学习：整句和词一起学，常用的词不会再被以前学过的整句一直压在后面。以前学过的整句不再读取，需要重新学
- 设置没能保存时会说明原因（超时、后台服务拒绝、写不进文件），等待时间延长到 10 秒；原因同时记在 logs 文件夹的 problems.log（只有出错的步骤和 Windows 的错误说明，不含打过的字），反馈问题时可以附上
- 命令行静默安装时 /D= 指定的目录对全新安装也生效（如用 scoop 安装）；界面安装时，可以选卸载后还在等重启删除的旧安装目录
- 诊断收集脚本在中文 Windows 上可以正常运行
