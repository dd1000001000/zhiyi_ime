- Fixed the candidate window sometimes going blank: the window stayed open but showed nothing, picking by number still worked, and only restarting the input method brought it back. It happened more often with monitors on different graphics cards. The window now draws in a sturdier way and rebuilds itself, or falls back to GDI, when drawing fails
- New "Candidate pages" setting (Settings → Keys): the previous page can be minus "-", comma "," or left bracket "[", the next page equals "=", period "." or right bracket "]", or none. Note: the default is now none, so "-" and "=" no longer turn pages unless you choose them here; PageUp / PageDown always do
