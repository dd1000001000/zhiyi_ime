- Learning mode gains "Number keys type the translation" (Settings → Learning): with it, a number types that candidate's translation and Ctrl+number the candidate itself; a candidate without a translation types nothing. With ten candidates on the page, 0 / Ctrl+0 is the tenth. It turns off when both Chinese and English candidate translations are off
- Offline translation offers more graphics cards (#8): the list now comes from Vulkan, so any discrete card with about 1 GB of its own memory can be chosen, and older cards such as a Radeon R5 M330 are no longer limited to the CPU. After choosing a card, its speed is compared with the CPU's, with a hint to use the CPU when the card is slower
- A number key with no candidate behind it (4–9 and 0 when three candidates are shown) now types the highlighted candidate and then the number; it used to be swallowed, and 0 could make the whole input vanish
- English typed in Chinese mode with Shift held (and "+", numpad digits and the like after pinyin): Space now types the text as shown and a space, where the whole text used to vanish; the window now shows that text too
