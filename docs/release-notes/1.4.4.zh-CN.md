- 学习模式新增“数字键直接打出翻译”（设置 → 学习）：勾选后按数字打出那个候选的翻译，Ctrl+数字打出候选本身；没有翻译的候选不上屏。这一页有 10 个候选时，第 10 个用 0 / Ctrl+0。中文和英文候选翻译都关闭时，这一项自动关闭
- 离线翻译可以选更多显卡（#8）：显卡列表改为直接询问 Vulkan，自带显存约 1 GB 以上的独立显卡都能选，像 Radeon R5 M330 这样的老显卡不再只能用 CPU。选好显卡后会和 CPU 比一下速度，显卡更慢时提示改用 CPU
- 候选不够时多出来的数字键（比如只有 3 个候选时的 4～9 和 0）改为先上屏高亮的候选再打出数字，以前会被吞掉，按 0 还可能让整段输入消失
- 中文模式下按住 Shift 打的英文（以及接在拼音后的“+”、小键盘数字等）：按空格改为原样上屏并带一个空格，以前整段会消失；这时候选窗也会显示正在打的文字，不再没有窗口
