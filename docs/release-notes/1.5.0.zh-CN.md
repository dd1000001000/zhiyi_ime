- 新增**语音输入**（设置 → 语音输入）：按快捷键说话，再按一次或点屏幕下方语音条上的停止键结束，说的话转成文字放进输入框，全程在本机识别，录音不保存、不上传。语音条的波形在有人说话时跳动；说话和识别时输入框暂停输入，按 Esc 或离开输入框放弃这次录音。识别结果带下划线：按退格或 Esc 删除，按回车确认（不换行，不会把聊天消息发出去），继续打字也会确认。支持普通话、英语、粤语和中英混说，数字和日期写成阿拉伯数字（可关闭）；没检测到人声、没有麦克风或麦克风权限关闭时在语音条位置提示。快捷键在“按键”页设置（新增的第五个切换键，可以是单独轻按 Shift / Ctrl 或组合键，默认没有）。语音模型（SenseVoice-Small，约 240 MB）在“语音输入”页按需下载，可在 CPU 或显卡上识别，选显卡时会先和 CPU 比一下速度。详见[语音输入](https://github.com/dd1000001000/zhiyi_ime/blob/main/docs/voice-input.md)
- 新增**自定义词表**（设置 → 自定义词表）：导入搜狗细胞词库 `.scel`、Rime 词库 `.dict.yaml`、带拼音的文本词库和英文词表，中文、英文各最多 64 份，每份可以单独启用或停用。导入的词和系统词一样出现在候选里、参加整句组句；拼音词库的词也能用双拼、简拼和五笔打，五笔词库的词也能用拼音打
- 英文单词联想：已打的原文固定在第一位，补全和拼写纠正最多两页，可以用 PageUp / PageDown 和设置的翻页键翻页；Tab / Shift+Tab 只在当前这一页里移动高亮，到头后回到另一端
- 推荐模型的“推理设备”现在列出自带显存 1 GB 以上的独立显卡（以前要 2 GB；模型在显卡上约占 500 MB），核显不再列出。推荐模型、离线翻译、语音输入三项的显存门槛都可以在配置文件里改（`laya.min_gpu_memory_mb`、`learning.translator_min_gpu_memory_mb`、`voice.min_gpu_memory_mb`）
- 升级前已经打开的程序要重新打开后才能使用语音输入（会在语音条位置提示重启）
