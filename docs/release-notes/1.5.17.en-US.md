- Fixed keys typed as pinyin in Aegisub and similar programs while the mouse is over the audio box, so its shortcuts did nothing (#37): a shortcut the program handles goes to the program first, and pinyin starts only when it does not
- Fixed the input method's open status as programs see it: open in both Chinese and English mode (it read closed before), as with Microsoft Pinyin. When a program or a system hotkey (Ctrl+Space when it is not a Zhiyi switch key) closes the input method, what is being typed is committed, keys then go to the program as typed and the mode shows English; a switch key, or Chinese / English in the menu, opens it again
- Learning mode: the model's translations now have parts of speech too (`adv./adj. fast` for 快 in 他跑得很快, `v. research` for 正在研究, `n. research` for 一项研究), judged from the text before the caret; by default those at least 0.4 likely, up to 3, which the config file can change (`learning.translator_pos_min_probability`, `learning.translator_pos_max_labels`). This needs the new translation model v4-1026: Settings > Learning, "Update to v4-1026"
- The offline translation model is now Zhiyi v4-1026: it has a part-of-speech head (about 10 MB); its COMET-22 on FLORES-200 / WMT24++ / NTREX-128 is 84.1 / 80.6 / 81.8 (v4: 84.0 / 80.5 / 81.7), and it picks the right meaning of 73.1% of ambiguous words it never saw (v4: 72.7%).
