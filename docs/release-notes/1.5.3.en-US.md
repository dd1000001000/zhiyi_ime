- Switch keys can be a tapped Alt, and a tapped modifier can be one side only (#12, thanks @w3c0929): in Settings → Keys, after setting a switch to Shift / Ctrl / Alt tapped alone, the arrow at the right of the box (or Alt + Down) picks "Left Ctrl only", "Right Ctrl only" and so on; the two sides can be different switches, such as left Ctrl for voice input and right Ctrl for Chinese/English. Either side still works by default, as before
- A modifier pressed while another is held (such as Ctrl + Shift for the keyboard layout) no longer counts as a tapped Shift that switches Chinese/English
- A hand-edited config with one side only (just `Control_L`, say) used to work on both sides; now only that side works
