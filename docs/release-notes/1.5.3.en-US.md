- Switch keys can be a tapped Alt, and a tapped modifier can be one side only (#12, thanks @w3c0929): in Settings → Keys, after setting a switch to Shift / Ctrl / Alt tapped alone, the arrow at the right of the box (or Alt + Down) picks "Left Ctrl only", "Right Ctrl only" and so on, and the other side does nothing. - A hand-edited config with one side only (just `Control_L`, say) used to work on both sides; now only that side works
