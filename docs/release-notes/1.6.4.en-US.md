- The recommendation model is now Zhiyi ML-Flash-1103: ML-pumpkin-1026 cut to 8 layers with one head for word choice and composition; same languages and inputs ([model notes](https://github.com/dd1000001000/zhiyi_models/releases/tag/model-ml-flash-1103))
- Faster recommendations: the new model computes the text before the caret once, and each key then computes only the typed pinyin and the candidates (`laya.context_cache`, on by default); a typical page (100 characters of context, 20 candidates) takes about 3.4 ms instead of 13.5 ms on the CPU with 4 threads, about 2.5 ms instead of 4 ms on a graphics card
- New word-choice test set end to end (with the word n-gram, after the pause, CPU), 1.6.3 → 1.6.4: Chinese words and word pairs 88.2% → 88.8%, initials only 77.7% → 79.1%, Chinese long input 76.0% → 76.3%, English 90.1% → 90.1%, English first letters only 77.0% → 77.0% (all within sampling error)
- New setting `laya.context_cache` (default true), see the settings guide
