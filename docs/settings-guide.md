# 设置指南

知意输入法有两种设置方式：**设置程序**（`zhiyi-settings.exe`，日常使用）和**配置文件**
（`default.json`，手工编辑，见文末“配置文件”，部分取值只能在这里改）。另外，任务栏上的“中/英”
提供快速切换。

## 打开设置

- 右键任务栏上的“中/英”，选择“设置…”；或者从开始菜单打开“知意输入法设置”。
- 设置程序只会打开一个窗口：再次打开时会切换到已经打开的窗口。
- 底部按钮：**确定**（保存并关闭）、**取消**（不保存）、**应用**（保存但不关闭）。保存后立即生效。
- 从任务栏菜单改过的状态，切换到设置的另一页时会自动刷新显示。

## 任务栏“中/英”

- **左键单击**：切换中文 / 英文。
- **右键菜单**：中文 / 英文；全拼 / 首字母 / 五笔 / 双拼（括号里是设置中选的方案，如“双拼（小鹤）”）；
  英文单词联想；中文标点；全角；设置…；关于；退出。打勾的项是当前状态，点一下即切换；输入方式与英文单词联想的
  改动会保存下来。双拼方案只在设置的“常规”页选。
- **鼠标悬停**：显示全部状态，例如“中文 · 全拼 · 半角 · 中文标点”或“中文 · 双拼（小鹤） · 半角 · 中文标点”。
- 开着大写锁定时图标显示 **A**。

## 常规

| 选项 | 说明 |
|------|------|
| 中文输入 | 启动时的输入方式：**全拼**（也能识别首字母简拼和混合输入，`wsyige` → 我是一个）、**首字母**（每个字母对应一个字，`zgr` → 中国人）、**五笔**（86 版）或**双拼**。打字时按“输入方式切换”键按 全拼 → 首字母 → 五笔 → 双拼 循环 |
| 双拼方案 | 微软双拼、小鹤双拼（默认）、自然码双拼、搜狗双拼或智能ABC双拼；换方案立即生效 |
| 主题 | 浅色或深色，候选窗口和设置程序一起切换 |
| 字号 | 小 / 中 / 大 |
| 候选排列 | 竖排（默认）或横排；学习模式的翻译只在竖排时显示 |
| 候选词数 | 每页 3–10 个，默认 7 |
| 界面语言 | 跟随系统、简体中文或 English；设置程序与任务栏菜单使用这个语言 |
| 英文输入 | 英文模式的输入方式：**单词联想**（默认，打几个字母就给出单词补全）或**只打字母**（每个键直接交给程序，适合终端和 vim）。打字时在英文模式按“输入方式切换”键或在任务栏菜单里也能切换，三处是同一个设置（`english.word_mode`） |
| 英文单词 · 拼写纠错 | 和“自动添加空格”在同一行。打错时在候选里给出正确拼写，第一个候选仍是原文，不会自动替换 |
| 英文单词 · 自动添加空格 | 默认勾选：英文模式里，用数字、鼠标或回车上屏的词后面加一个空格；不勾时只上屏这个词。用空格或标点上屏时总是只跟那个符号（`hello` + 逗号 → `hello,`）。学习模式打出的英文等带空格的语言（`learning.space_languages`）的翻译也照此加空格。中文模式里夹的英文候选不管怎么上屏都不加空格，和中文候选一样（`engine.auto_space`） |
| 表情符号 · 拼音候选里显示 emoji | 默认勾选：拼音第一页里有 emoji 的词后面跟着它的 emoji（打 `xiao`，“笑”后面是 😄 ☺️），每页最多 3 个，第一个候选总是文字；选了 emoji 不记学习。全部 emoji 可以用 `/bq` 浏览（`engine.emoji_candidates`） |
| 推理设备 | 只在这台电脑有可用的独立显卡（Direct3D 12、自带显存 1 GB 以上，核显不算；门槛见配置项 `laya.min_gpu_memory_mb`）时出现：`CPU（型号）`（默认；多路 CPU 显示为 `CPU（2 × 型号）`），以及每块显卡 `GPU（型号）`（有几块时为 `GPU 1（型号）`、`GPU 2（型号）`，同型号的两块卡也分开列出）。选显卡时先在后台把推荐模型分别放到显卡和 CPU 上各跑一遍测速，下方显示两边的耗时；显卡比 CPU 慢时这行字变成黄色并建议改用 CPU，但选择保留，由用户决定。模型在这块卡上跑不起来时改回 CPU，这块卡以后不再列出（换了驱动会重新列出）。测速结果按显卡和驱动版本记在本机数据目录的 `laya-gpu.json`（见下面的“数据位置”）。显卡上约占 500 MB 显存和 200 MB 内存；显卡不在或加载失败时自动用 CPU |
| 上文推荐 · 按上文推荐候选和组长句（中文和英文） | 默认勾选：本机的推荐模型读取光标前的文字，把最合适的候选排到第一位并标上星号，长拼音停顿后由模型组句；中文和英文一起开关（`laya.enable`）。不勾时候选按词频和学习记录排列，下次启动不再加载模型 |
| 上文推荐 · 只把拼音完全对上的候选提到首位 | 默认不勾。勾选后：拼音输入时，候选里有拼音完全对上的词（每个音节都打全，例如打 `xian` 时的“先”“现”“西安”），推荐只会把这样的词放到第一位；只打了一半的音节（`xian` 补成 xiang 的“想”）或只打声母（`lo` 的“了哦”）的候选留在原来的位置。开了模糊音时，所选模糊音组的读法也算对上（开了 an=ang，`xian` 的“想”就算）。没有完全对上的候选时（如简拼 `zg`）照常推荐。不勾时推荐可以把任何候选放到第一位，末音节没打完时（`jinti` 想打“今天”）也能推荐出想要的词。“上文推荐”不勾时这一项变灰（`laya.exact_pinyin_first`） |
| 数据 · 数据位置 | 词库、学习记录、语言包、日志、推荐模型的缓存和下载的翻译模型存放的文件夹，默认 `%USERPROFILE%\zhiyi\`（本机缓存在 `%LOCALAPPDATA%\zhiyi\`）。“更改…”选一个文件夹（如 D 盘）后，数据放到 `<所选文件夹>\zhiyi\`，本机缓存放到其中的 `local\`：先关闭输入法后台，复制并逐个核对文件大小，再改用新位置、重启后台，最后删除原位置的数据。新位置已有知意的数据（如重装系统后）时可以选择沿用那里的数据。复制出错时什么都不改，原数据保持不变。“恢复默认”把数据搬回 C 盘。所选位置暂时无法访问（如移动硬盘未连接）时使用默认位置，这一行会提示 |
| 启动 · 开机时自动启动 | 默认勾选：登录时启动后台服务 `zhiyi-server.exe`。不勾时登录不启动，第一次切换到知意输入法时才启动，要等几秒（加载词典和推荐模型）才能打字 |

任务栏“中/英”右键菜单的“退出”关闭后台服务，释放它占用的内存；之后知意输入法暂时打不了字，
再次切换到知意输入法（例如按 Win+空格 换到别的输入法再换回来）或打开新的程序时自动重新启动。

### 双拼

- 两个键一个字：前一个键是声母，后一个键是韵母，按所选方案的键位；只打了声母时也出候选。零声母字按各方案自己的规则
  （如小鹤 `aa` 啊、`an` 安；智能ABC 的 a、e、v 是 zh、ch、sh，零声母一律以 o 开头，如 `oa` 啊、`oj` 安）。微软双拼的 `;` 在打字过程中是韵母键（ing），没在打字时仍是标点。
- 输入框显示实际按下的键（如 `nihc`），选了一部分候选后显示“已选的字 + 剩下的键”（如 `你hc`）。
- 与全拼共用词库、自学习、用户词和上文推荐（推荐模型读的是换算后的全拼）；模糊音的设置同样适用于双拼。
- 中文模式里夹英文单词：双拼下几乎任何字母串都能切成音节，所以只有整串切不出双拼时才给英文单词候选。
- 打字途中切换全拼 / 首字母 / 双拼时，已经打的键按新的方式重新出候选（切换前后输入框里的键不变，`;` 离开双拼时去掉）；
  切入或切出五笔时清空正在打的内容。
- 设置中选的方案的拼写表缺失时（安装不完整），双拼按全拼处理，切换键跳过双拼。

## 模糊音

总开关加 10 组模糊音：z=zh、c=ch、s=sh、n=l、l=r、f=h（声母）和 an=ang、en=eng、in=ing、wang=huang（韵母）。
an=ang 也包括 ian=iang、uan=uang。新安装默认打开总开关，各组都不勾；1.5.16 以前用过的用户，没自己选过的仍是
en=eng、in=ing。声母、韵母各最多模糊一次：同时勾了 n=l 和 l=r 时，n 和 r 不互通；勾了 z=zh 和
an=ang 时，`zan` 仍会出“张”；wang=huang 不和其他组叠加。模糊匹配出的词排在原音之后，并在后面用括号标出正确拼音，如 `zongguo` → 中国(zhong guo)。

## 按键

五个切换键：

| 切换键 | 默认 | 作用 |
|--------|------|------|
| 中英切换 | 轻按 Shift | 中文 / 英文 |
| 输入方式切换 | Ctrl + Space | 中文：全拼 → 首字母 → 五笔 → 双拼 循环；英文：单词联想 / 逐字母 |
| 中英文标点 | Ctrl + . | 中文标点 / 英文标点 |
| 全角/半角 | Shift + Space | 全角 / 半角 |
| 语音输入 | 不使用 | 开始说话 / 结束说话；右边选“点按两次”（按一下开始、再按一下结束）或“长按”（按住说话、松开结束），见 [语音输入](voice-input.md) |

- **左键**点击按键框后按下新的按键（Esc 取消），**右键**点击清空（不使用这个切换键）。
- 录入时按键先交给按键框，其他程序的全局热键、知意的“打开/关闭输入法”热键和输入法都不会先拿走它，所以被其他程序占用的组合也能录到（录到后提示“已被其他程序占用”），录入时也不会触发那个程序。Win 组合键、Alt+Tab、Alt+Esc、Ctrl+Esc 照常切换窗口，录入随之取消。
- 每个切换键都可以是单独轻按 Shift 或 Ctrl（同一个键只能给一项），或者组合键：Ctrl / Alt 组合、Shift + Space 或 F1–F11。
  轻按修饰键默认不分左右（任意一侧都算）。点按键框右侧的箭头（或按 Alt + ↓），可以选“只认左 Ctrl”“只认右 Ctrl”这样只认一侧，
  同一个修饰键只能给一项：某一项用了右 Ctrl，左 Ctrl 也不能再给别的切换键。
  很多新笔记本没有右 Ctrl（换成了 Copilot 键）。按住一个修饰键时再按另一个（如 Ctrl + Shift 切换键盘布局）不算轻按。
  配置文件里是 `ascii_composer.switch_key` 的 `Shift_L` `Shift_R` `Control_L` `Control_R`：中英切换为 `code`，另外四项为 `toggle_style` `toggle_punct` `toggle_shape` `toggle_voice`；左右两侧同值表示不区分，只写一侧表示只认该侧。
  不能设成单独轻按 Alt：Windows 不把 Alt 键交给输入法，设了也不会触发。
- 不能和其他切换键重复，也不能用复制、粘贴等常用快捷键；重复时保留原来的设置。
- 按键框下方的提示：灰色“已接管系统的××热键”表示和 Windows 输入法热键相同，由知意输入法处理；
  黄色“已被其他程序占用，可能无效”表示其他程序注册了这个全局热键。
- “恢复默认”把五个切换键恢复为上表的默认值（会先确认）。
- 配置文件中这五项无效（例如手工改出了重复的键）时，会自动恢复默认值。
- 学习模式下打字时，Ctrl+1～9 打出那个候选的翻译（见 [学习模式](learning-mode.md#打出翻译)），不能更改。

### 候选翻页

有候选时用来翻页的键，两项都默认“不使用”：

| 项 | 可选 |
|----|------|
| 上一页 | 不使用、`-` 减号、`,` 逗号、`[` 左方括号 |
| 下一页 | 不使用、`=` 等号、`.` 句号、`]` 右方括号 |

- PageUp / PageDown 不管这里怎么选都能翻页；要单独按下（不带 Shift、Ctrl、Alt）才算翻页键。
- 选了的键只在有候选时翻页（拼音、五笔、双拼、`/` 符号输入和英文单词联想都一样），没在打字时照常打出符号。所以选了逗号或句号后，要在拼音或英文单词后面直接打出逗号、句号，得先按空格上屏。
- 英文单词联想的候选和拼音一样最多两页（每页候选数 × 2），也用这些键和 PageUp / PageDown 翻页。
- ↑ / ↓ 逐个移动高亮，到一页的头尾时翻页；Tab / Shift+Tab 只在当前这一页里移动，走到最后一个回到第一个，反之亦然，中英文一样。Ctrl+Tab、Alt+Tab 和没在打字时的 Tab 照常交给程序。
- 配置文件里是 `shortcuts.page_up` / `shortcuts.page_down`，值为 `""`（不使用）或上表中的一个符号；写成其他内容时按“不使用”处理。

## 词库

- **自学习**：选过一次的词会往前排，选过两次的词固定在最前面，逐字选出的新词也会被记住；长期不用的记录会自己淡掉。
  学过的词用简拼、混拼或者没打完时同样有效（打全 现在 之后，`xz` 也先出 现在）。
  刚上屏就按 Backspace 可以撤销这次学习。
  英文也会记住选过的纠正和常打的新词。
- **清除学习记录**：删除全部学习记录（会先确认，无法撤销）。

### 备份与迁移

换电脑或重装时，用“词库”页下方的“备份与迁移”把设置、词库和学习记录带过去：

- **导出…**：选一个文件夹，生成 `知意输入法备份-<日期>-<时间>.zhiyi-backup`（下次默认还是这个文件夹）。
  备份里有：所有设置（隐私的两档勾选和开发诊断设置除外，它们只属于这台电脑），自造词、调整过的候选顺序、
  删除的系统词，拼音、五笔、组词和英文的学习记录，以及导入的自定义词表（没有导入过时不写这一项，
  旧版本的知意也能导入这份备份）。有未应用的更改时会先问要不要应用。
- **导入…**：选一个备份文件，确认后导入全部内容。设置覆盖本机的设置；词库和学习记录与本机现有的合并，
  不会丢掉本机学到的词。备份文件缺少内容、格式不对或已损坏时，**什么都不导入**。
- 导入后无法撤销，所以导入前会问要不要先备份本机当前的数据：选“是”就像“导出…”一样选文件夹导出一份，
  导出成功才继续导入（取消或失败则不导入）；导错了可以导入这份恢复设置。
- 备份里设了候选翻译、本机却没有对应的语言包时，导入后会提示去“学习”页下载。
- 备份文件包含你打过的词，请妥善保管。语言包、日志和体验改进记录不在备份里。
- 导入备份时，本机已有的词表（同一份导入记录）不重复添加，其余的词表加进来，保持备份时的启用状态。

## 自定义词表

导入别处的词库（专业词汇、游戏用语、地名等），打字时这些词和系统词典的词一样出现在候选里：

- **支持的格式**（导入时按文件内容自动识别，不用选）：
  - 搜狗细胞词库 `.scel`（搜狗词库网站下载的）；
  - Rime 词库 `.dict.yaml`：拼音的、五笔的或英文的，按文件头的 `columns` 读各列；
  - 带拼音的文本词库：搜狗导出的 `'a'li'ba'ba 阿里巴巴`、QQ 导出的 `a'li'ba'ba 阿里巴巴 1`、
    `阿里巴巴<Tab>a li ba ba<Tab>100` 等，UTF-8、UTF-16 或 GBK 编码都可以；
  - 英文词表：一行一个词或短语，后面可以跟一个词频（Tab、逗号或空格隔开）；单词本导出的 `abandon,放弃` 只取第一列。
  - 没有拼音的中文词表暂不支持；其他输入法的格式（如百度 `.bdict`、QQ `.qpyd`）可以先用“深蓝词库转换”转成
    Rime 或搜狗文本格式再导入。
- **导入词表…**：选文件的窗口里可以按格式筛选：所有支持的格式（默认）、搜狗细胞词库（`.scel`）、Rime 词库
  （`.dict.yaml`）、文本词库（`.txt` `.csv` `.tsv`），以及所有文件。后缀不是这几种的文件选了也不导入，当场提示。
  选好后先显示文件里有多少词、新增多少、系统已有多少（不导入）、多少能用拼音和五笔打，确认后才导入。
  系统词典里已有的词（同字同音）不重复导入，不改变它们的排序。
- **限制**：中文、英文词表各最多 64 份，满了要先删掉不用的；同一个文件（内容完全相同）只能导入一次，
  再选时提示它对应的词表；文件不能超过 64 MB。
- **打法**：拼音词库里的词可以用全拼、简拼、混拼、双拼和首字母打，也会参加整句组句；五笔编码按五笔 86 的组词规则
  （两字取各字前两码，三字取前两字首码和末字前两码，四字以上取第一、二、三和最后一个字的首码）由各字的全码算出。
  五笔词库里的词则从字推出拼音：先找系统词典里有的词，多音字只取一个读音，可能读错；这样的词在列表里标出数量，
  点“查看读音”可以看推出的拼音。英文词表的词在英文模式下补全，不会被当成拼写纠错的目标。
- **排序**：导入的词按词频和系统词一起排：两字词按 1000、三字以上按 500 计（比系统词典里大部分长词的 100 高，
  比常用词低）；文件自带词频时，按名次在这个值的一半到两倍之间分配（搜狗细胞词库里的数字只是序号，不当词频）。
  五笔里导入的词排在同码的系统词之后，原来的位置不变。选过两次以后和别的词一样靠自学习排到前面。
- **勾选 / 取消勾选**：启用或停用这份词表，立即生效，不用点“应用”。停用后它的词不再出现，打字时学到的这些词的
  选择记录也一起隐藏，重新勾选后恢复。
- **删除**：删除这份词表，以及只属于它的词的学习记录（会先确认，无法撤销）。
- 词表保存在数据文件夹的 `wordlists\`（`index.json` 和每份词表一个 `.tsv`），换数据位置时一起搬走；
  导入后原文件就不再需要了。`index.json` 损坏或丢失时，按 `wordlists\` 里的词表文件重新生成（损坏的文件改名为
  `index.json.damaged` 留着），词表都还在，都是启用状态，但导入时的统计数字和“已导入过”的记录没有了。

## 语音输入

按快捷键说话，转成文字放进输入框，全程在本机识别，见 [语音输入](voice-input.md)。

- **开启语音输入**：下载语音模型后才能勾选；下载完成后自动勾选（点“确定”或“应用”保存）。
- **快捷键**：显示“按键”页设的语音输入快捷键，点“在‘按键’页设置”过去修改；没设时快捷键不起作用。
- **语音模型**：SenseVoice-Small，约 240 MB。未下载时只有“下载”；装好后有“检查更新”和“卸载”，有新版本时变成
  “更新到 vN”。卸载后语音输入关闭。
- **识别设备**：CPU（一句话约 0.1 秒）或显卡（DirectML，列表和“常规”页的推荐模型一样）。选显卡时先测速度：
  识别 5 秒语音在这块显卡和 CPU 上各要多久，显卡更慢时提示建议改用 CPU；跑不起来的显卡退回 CPU 并不再列出。
  下载模型后也会在所选设备上测一次。
- **识别语言**：自动、普通话、英语、粤语。
- **数字和日期写成阿拉伯数字**：默认打开（“3点”“10月15号”）。
- 一次最长录音时长只在配置文件里改（`voice.max_seconds`，默认 60 秒）。

## 学习

打字时顺便学外语：候选窗口在每个候选后面显示它的外语意思和词性（最多三个常用义项），见 [学习模式](learning-mode.md)。

- **候选翻译**：中文候选翻译成英、日、韩、法、德、西、俄之一，英文候选翻译成中、日、韩、法、德、西、俄之一；
  只能选已安装语言包的语言，其他语言是灰色的。打开任意一项时“候选排列”改为竖排。右侧预览按所选语言显示示例。
- **语言包**：“中文 → 外语”“英文 → 外语”各 7 个。未安装的只有“下载”；装好的有“检查更新”和“卸载”，
  有新版本时变成“更新到 vN”。安装包自带中 → 英、英 → 中，也可以卸载，再点“下载”从安装目录恢复。
  语言包装上或卸载后立即生效。
- **离线翻译**：语言包里没有的词、词组和短句（3–7 个一页），用下载到本机的翻译模型（从腾讯 Hy-MT2-7B 蒸馏，约 0.4 GB）
  翻译，见 [学习模式](learning-mode.md#离线翻译)。“运行在”选自带显存约 1 GB 以上的独立显卡或 CPU（CPU 上一页约 0.3 秒）。
  点“下载”后下载模型和运行库，装好后自动打开并在所选的显卡或 CPU 上试翻一句；试翻失败时关闭。
  装好后可以“检查更新”“卸载”。

## 隐私

用户体验改进计划，两档都默认关闭，记录只保存在本机：

- **加入用户体验改进计划**：记录版本、设置和出错情况等基本信息，不含任何输入内容。
- **允许收集您的输入信息**：还会记录输入内容、使用统计和正在使用的程序；勾选时会先确认，并同时勾选上一项。

取消勾选后立即停止记录，已有记录保留；“删除所有记录”删除两档的全部记录，“打开日志文件夹”查看记录文件。
每项记录的具体内容见 [隐私说明](privacy.md)。

## 更新

- **有新版本时提醒我**（默认打开）：打开设置时检查 GitHub 上的最新版本，有新版本时弹出提醒
  （立即更新 / 稍后提醒 / 跳过这个版本）。检查只下载版本信息，不发送任何数据。
- **检查更新**：随时手动检查。
- **立即更新**：下载安装包（可取消，中断后继续下载），校验签名和 SHA-256 后启动安装程序（需要管理员确认），
  设置窗口随之关闭；安装完成后重新打开设置并显示“已更新”。已经打开的程序重新打开后才会用上新版本。
